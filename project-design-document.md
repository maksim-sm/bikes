## 1. Цели и контекст

### 1.1. Задача

Сделать быстрый и удобный фронтенд интернет-магазина велосипедов всех типов для покупателей из Беларуси. Пользователь должен легко найти подходящую модель, сравнить её с другими, подобрать размер рамы и оформить заказ с оплатой и доставкой, привычными для белорусского рынка.

### 1.2. Бизнес-цели

1. Конверсия из просмотра каталога в заказ — не ниже 2%.
2. Меньше возвратов из-за неправильного размера — за счёт подбора велосипеда и калькулятора размера рамы.
3. Повторные покупки — через личный кабинет, избранное и историю заказов.
4. Органический трафик из поиска (Яндекс, Google) — SEO-оптимизированные страницы категорий и товаров.

### 1.3. Целевая аудитория

| Сегмент | Потребности | Что для них важно в интерфейсе |
| --- | --- | --- |
| Городские велосипедисты (25–45 лет) | Велосипед для поездок на работу и прогулок | Понятные фильтры, рассрочка/ЕРИП, доставка по Минску |
| Любители спорта (20–40 лет) | Шоссейные, гравийные, горные модели | Подробные характеристики, сравнение, отзывы |
| Родители | Детские и подростковые велосипеды | Подбор по росту/возрасту ребёнка |
| Новички | Первый велосипед, не разбираются в характеристиках | Пошаговый подбор, простые объяснения терминов |
| Жители регионов | Покупка без визита в магазин | Доставка, оплата при получении |

### 1.4. Вне рамок проекта (v1)

- Реальный бэкенд, база данных и интеграция с эквайрингом — на старте используются **моки** (см. раздел 8).
- Запчасти, аксессуары, экипировка, электровелосипеды.
- Административная панель (управление товарами и заказами).
- Мобильное приложение.
- Другие языки (белорусская версия — кандидат в v2).

## 4. Ключевые пользовательские сценарии

1. **Покупка известной модели**: Поиск → Карточка товара → Выбор размера и цвета → Корзина → Оформление → Оплата.
2. **Покупка новичком**: Главная → «Подобрать велосипед» → Квиз (5–6 шагов) → Подборка с объяснением, почему модели подходят → Карточка → Заказ.
3. **Выбор из нескольких моделей**: Каталог с фильтрами → «Добавить к сравнению» (до 4 шт.) → Таблица сравнения с подсветкой различий → Карточка → Корзина.
4. **Покупка детского велосипеда**: Категория «Детские» → Фильтр по росту ребёнка → Карточка с таблицей ростовок → Заказ.
5. **Повторная покупка / отслеживание**: Вход → Личный кабинет → История заказов → Статус заказа.
6. **Отзыв после покупки**: Личный кабинет → Заказ со статусом «Получен» → «Оставить отзыв» → Оценка + текст + фото.

## 5. Описание страниц

### 5.1. Глобальные элементы

**Шапка (Header)** — закреплена при скролле, на мобильных сворачивается.
- Логотип, главное меню с мега-меню категорий (с картинками).
- Строка поиска с подсказками (модели, бренды, категории).
- Иконки: сравнение (счётчик), избранное (счётчик), личный кабинет, корзина (счётчик + сумма).
- Верхняя полоса: телефон (`+375 (XX) XXX-XX-XX`), режим работы, «Доставка по всей Беларуси».

**Подвал (Footer)**
- Навигация по категориям и информационным страницам.
- Способы оплаты (логотипы Visa, Mastercard, БЕЛКАРТ, ЕРИП «Расчёт»).
- **Обязательные реквизиты продавца** по законодательству РБ: наименование, УНП, юридический адрес, номер и дата регистрации в Торговом реестре, контакты для обращений покупателей.
- Ссылки на политику обработки персональных данных и публичный договор.

**Мобильная навигация** — нижняя панель (Главная, Каталог, Подбор, Корзина, Кабинет) для экранов < 768 px.

### 5.2. Главная

| Блок | Содержимое |
| --- | --- |
| Первый экран | Крупная фотография велосипеда в реальной среде (белорусский пейзаж/город), заголовок, две кнопки: «Каталог» и «Подобрать велосипед» |
| Категории | Плитки категорий с фото |
| Подбор | Промо-блок квиза с первым вопросом прямо на главной (клик → переход в `/podbor` с уже выбранным ответом) |
| Хиты продаж / Новинки | Карусели карточек товаров (табы) |
| Бренды | Логотипы брендов-ссылок на отфильтрованный каталог |
| Преимущества | Доставка, гарантия, бесплатная предпродажная настройка, оплата при получении — только реальные, проверяемые утверждения |
| Отзывы | 3–4 последних отзыва с рейтингом и ссылкой на товар |

### 5.3. Каталог / категория

- Хлебные крошки, заголовок H1, количество товаров.
- **Фильтры** (слева на десктопе, в шторке `Sheet` на мобильных):
  цена (слайдер + поля), бренд, диаметр колёс, размер рамы, материал рамы, тип тормозов, количество скоростей, тип подвески, рост велосипедиста, год модели, цвет, наличие, рейтинг.
- Активные фильтры — чипсы над списком со сбросом по одному и «Сбросить всё».
- Сортировка: по популярности, цене (↑/↓), новизне, рейтингу, размеру скидки.
- Вид: сетка (по умолчанию) / список.
- Пагинация с кнопкой «Показать ещё» + номера страниц (для SEO).
- Состояние фильтров хранится **в URL** (`?brand=merida&wheel=29&price=800-2500`) — ссылкой можно поделиться, работает кнопка «Назад».

**Карточка товара в списке**: фото (смена второго фото при наведении), бейджи («Новинка», «−15%», «Хит»), бренд, название, рейтинг и количество отзывов, ключевые характеристики (колёса, рама, скорости), цена и старая цена, наличие, кнопки «В корзину», «В избранное», «Сравнить».

### 5.4. Карточка товара

- Галерея (миниатюры + зум, полноэкранный просмотр, свайп на мобильных).
- Бренд, название, артикул, год модели, рейтинг → якорь на отзывы.
- Цена, старая цена, статус наличия («В наличии», «Под заказ, 3–5 дней», «Нет в наличии — сообщить о поступлении»).
- Выбор цвета (свотчи) и размера рамы (кнопки S/M/L/XL с ростом: «M — 170–180 см»), ссылка «Как подобрать размер?» → калькулятор в диалоге.
- Кнопки: «В корзину», «Купить в 1 клик» (имя + телефон), «В избранное», «Сравнить».
- Блок доставки: ориентировочная дата и стоимость для выбранного города.
- Табы/секции: «Описание», «Характеристики» (сгруппированная таблица: рама, вилка, трансмиссия, тормоза, колёса, вес), «Геометрия» (таблица по размерам), «Отзывы», «Доставка и оплата».
- Блок «С этим велосипедом сравнивают» и «Похожие модели».
- Закреплённая панель с ценой и кнопкой «В корзину» на мобильных при прокрутке.

### 5.5. Подбор велосипеда (квиз)

Пошаговая форма с прогресс-баром, кнопкой «Назад» и возможностью пропустить шаг.

1. Для кого? (для себя / для ребёнка / в подарок)
2. Где будете кататься? (город, парк и грунтовки, лес и бездорожье, шоссе, трюки)
3. Как часто? (иногда / несколько раз в неделю / тренировки)
4. Рост (и длина ноги — опционально, для точности).
5. Бюджет (диапазоны в BYN).
6. Важные особенности (лёгкий вес, складной, багажник, амортизация).

Результат: 3–6 рекомендованных моделей с объяснением соответствия («Подходит для лесных тропинок, размер M под ваш рост 176 см»), кнопка «Показать все подходящие» → каталог с проставленными фильтрами. Ответы сохраняются в URL, чтобы результатом можно было поделиться.

### 5.6. Калькулятор размера рамы

Отдельная страница и переиспользуемый диалог. Ввод: тип велосипеда, рост, длина ноги (опционально). Вывод: рекомендуемый размер (S/M/L/XL и в дюймах/см) + иллюстрация, как измерить длину ноги. Логика — таблицы соответствия по типам велосипедов в `lib/sizing.ts`.

### 5.7. Сравнение

- До 4 товаров (на мобильных — 2 с горизонтальной прокруткой).
- Табы по категориям, если в сравнении товары разных типов.
- Переключатель «Только различия».
- Закреплённая шапка с фото, ценой и кнопкой «В корзину».
- Хранение: локально для гостя, синхронизация с аккаунтом после входа.

### 5.8. Избранное

Сетка карточек, сортировка, уведомление о снижении цены (бейдж «Цена снизилась»), «Добавить всё в корзину». Хранение аналогично сравнению.

### 5.9. Корзина

- Список позиций: фото, название, цвет/размер, количество (степпер, лимит по остатку), цена, удаление с возможностью отмены (toast «Товар удалён. Вернуть»).
- Промокод.
- Итог: сумма товаров, скидка, доставка («рассчитывается на следующем шаге»), итого.
- Предложение услуг: «Предпродажная настройка», «Сборка при доставке».
- Пустое состояние с ссылками на подбор и хиты продаж.

### 5.10. Оформление заказа

Одна страница с секциями (без лишних шагов), сводка заказа справа (на мобильных — сворачиваемая сверху).

1. **Контакты**: имя, фамилия, телефон (маска `+375 (__) ___-__-__`, коды 25/29/33/44), e-mail (для чека и статусов). Гость может оформить заказ без регистрации; галочка «Создать аккаунт».
2. **Доставка** (см. 6.2): выбор способа → поля адреса или выбор пункта выдачи → дата/интервал для курьера.
3. **Оплата** (см. 6.1).
4. Комментарий к заказу.
5. Согласие с публичным договором и **отдельное согласие на обработку персональных данных** (требование Закона РБ № 99-З «О защите персональных данных»), без предустановленной галочки.
6. Кнопка «Подтвердить заказ» с итоговой суммой.

Страница успеха: номер заказа, состав, способ оплаты, следующие шаги (для ЕРИП — номер счёта и инструкция по оплате).

### 5.11. Личный кабинет

| Раздел | Функции |
| --- | --- |
| Обзор | Последний заказ и его статус, быстрые ссылки |
| Заказы | Список со статусами (Новый, Подтверждён, Собирается, Передан в доставку, Готов к выдаче, Получен, Отменён), фильтр, детали заказа, повтор заказа |
| Адреса | CRUD адресов доставки, адрес по умолчанию |
| Отзывы | Мои отзывы, товары, ожидающие отзыва |
| Избранное и сравнение | Ссылки на синхронизированные списки |
| Профиль | Имя, телефон, e-mail, смена пароля, подписка на рассылку, удаление аккаунта |

Авторизация: e-mail + пароль (на моках — имитация сессии; реальная реализация на этапе подключения бэкенда).

### 5.12. Отзывы и рейтинги

- На карточке товара: средняя оценка, распределение по звёздам (гистограмма), фильтр по оценке, «С фото», сортировка (новые/полезные).
- Отзыв: оценка 1–5, «Достоинства», «Недостатки», «Комментарий», срок использования, рост автора и выбранный размер (полезно для других покупателей), до 5 фото.
- Бейдж «Покупка подтверждена» для отзывов от покупателей.
- «Полезен ли отзыв?» (да/нет).
- Оставлять отзывы могут только авторизованные пользователи; публикация после модерации (статус «На модерации» в кабинете).

### 5.13. Информационные страницы

«Доставка и оплата», «Гарантия и возврат» (с учётом Закона РБ «О защите прав потребителей»: велосипед — технически сложный товар, условия возврата/обмена описываются отдельно), «Контакты» (карта магазинов, часы работы), юридические страницы.

## 6. Специфика Беларуси

### 6.1. Оплата

| Способ | Описание | Реализация в v1 (моки) |
| --- | --- | --- |
| Наличными или картой при получении | Курьеру или в пункте выдачи/магазине | Заказ создаётся сразу, статус «Новый» |
| Онлайн картой | Visa, Mastercard, БЕЛКАРТ через белорусский эквайринг (bePaid / WEBPAY — выбор провайдера на этапе бэкенда) | Имитация страницы оплаты с успешным/ошибочным исходом |
| ЕРИП («Расчёт») | Оплата через интернет-банкинг, банкомат, инфокиоск | Генерация мок-номера счёта + инструкция: «Платежи ЕРИП → Интернет-магазины → [Название] → номер заказа» |

Архитектура платёжного модуля — через интерфейс `PaymentProvider`, чтобы мок заменялся реальным провайдером без изменений UI.

### 6.2. Доставка

| Способ | Зона | Сроки (ориентир) | Примечание |
| --- | --- | --- | --- |
| Курьер по Минску | Минск и МКАД | 1–2 дня, выбор интервала | Опция «Сборка и настройка при доставке» |
| Курьер по Беларуси | Областные и районные центры | 2–4 дня | |
| Европочта | Пункт выдачи по всей РБ | 2–5 дней | Выбор отделения из списка/карты |
| Белпочта | Отделение почты | 3–7 дней | Для небольших населённых пунктов |
| Самовывоз | Магазин/склад | В день заказа при наличии | Бесплатно |

Адрес: область (6 областей + г. Минск), населённый пункт (с автодополнением), улица, дом, корпус, квартира, почтовый индекс (6 цифр).

### 6.3. Форматы

| Данные | Формат | Пример |
| --- | --- | --- |
| Цена | `Intl.NumberFormat('ru-BY', { style: 'currency', currency: 'BYN' })` с выводом «р.» | `1 249,00 р.` |
| Дата | `ru-BY`, ДД.ММ.ГГГГ / «20 октября» | `20.10.2026` |
| Телефон | `+375 (XX) XXX-XX-XX` | `+375 (29) 123-45-67` |
| Индекс | 6 цифр | `220030` |
| Размеры | Дюймы для колёс, см/дюймы для рам | `29"`, `M (18")` |

Цены в данных хранятся **в копейках (целые числа)**, чтобы избежать ошибок округления. Все форматтеры — в `lib/format.ts`.

### 6.4. Тексты и склонения

- Все строки интерфейса — в `lib/i18n/ru.ts` (словарь), даже при одном языке: облегчает правки и будущую белорусскую версию.
- Склонение числительных через `Intl.PluralRules('ru')`: «1 товар, 2 товара, 5 товаров», «1 отзыв, 3 отзыва, 11 отзывов».
- Обращение к покупателю — на «вы» (со строчной буквы), тон дружелюбный и конкретный, без канцелярита.

## 7. Визуальный дизайн

### 7.1. Направление

**«Мастерская»**: чистый технический стиль, вдохновлённый велома��терской и инженерной документацией — точные характеристики, ясная типографика, крупные фото велосипедов как главный элемент. Фирменный «сигнальный» элемент — **жёлто-оранжевый акцент, как светоотражатель**, используемый строго для главных действий и бейджей скидок. Интерфейс вокруг — спокойный, чтобы велосипеды на фотографиях были в центре внимания.

### 7.2. Цвета (5 цветов)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--background` | `#F4F5F2` (холодный светло-серый) | Фон страниц |
| `--card` | `#FFFFFF` | Карточки, поверхности |
| `--foreground` | `#1B1E22` (графит) | Основной текст, иконки |
| `--primary` | `#1E4D8C` (кобальт, «цвет рамы») | Ссылки, активные состояния, выбранные фильтры |
| `--accent` | `#FFB21E` (светоотражатель) | Основная кнопка «В корзину», бейджи скидок, фокус |

Производные токены (`--muted`, `--border`, `--muted-foreground`) — оттенки графита с прозрачностью. Контраст текста — не ниже WCAG AA (4.5:1); на акцентном цвете используется графитовый текст. Тёмная тема — в v2.

### 7.3. Типографика (2 семейства, обе с кириллицей)

| Роль | Шрифт | Использование |
| --- | --- | --- |
| Заголовки | **Unbounded** (Google Fonts, cyrillic) | H1–H3, цены на карточке товара, названия категорий |
| Текст | **Onest** (Google Fonts, cyrillic) | Основной текст, интерфейс, таблицы характеристик (`tabular-nums`) |

Подключение через `next/font/google` с `subsets: ['cyrillic', 'latin']`. Размер основного текста — 16 px, минимум — 14 px, межстрочный интервал — 1.5. Заголовки — с `text-balance`.

### 7.4. Сетка, отступы, формы

- Mobile-first; брейкпоинты Tailwind: `sm 640`, `md 768`, `lg 1024`, `xl 1280`, контейнер до 1360 px.
- Сетка каталога: 2 колонки (мобильный) → 3 (lg) → 4 (xl).
- Скругления: `--radius: 0.5rem` (карточки), кнопки — 0.375rem.
- Отступы — шкала Tailwind, промежутки через `gap-*`.

### 7.5. Изображения и анимация

- Фото товаров на однородном светлом фоне, соотношение 4:3; лайфстайл-фото — на главной и в категориях.
- Анимация — сдержанная: появление карточек при загрузке, плавное открытие шторок и мега-меню, «полёт» товара в корзину. Учитывается `prefers-reduced-motion`.

## 8. Данные и моки

### 8.1. Подход

- Фронтенд работает через **слой API-клиента** (`lib/api/*`), который вызывает Route Handlers Next.js (`app/api/*`), отдающие моковые данные из `data/*.ts`.
- Контракт ответов совпадает с будущим реальным API: при подключении бэкенда меняется только реализация обработчиков/базовый URL.
- Имитация задержки (200–600 мс) и ошибок в dev-режиме для проверки состояний загрузки и ошибок.
- Мок-каталог: ~60 моделей, 8–10 брендов, все категории из 3.2, сгенерированные фотографии.

## 10. Компоненты и состояния

Каждый компонент, загружающий данные, должен иметь состояния: **загрузка** (скелетоны той же формы), **пусто** (понятный текст + действие), **ошибка** (сообщение + «Повторить»), **успех**.

Ключевые переиспользуемые компоненты: `ProductCard`, `Price` (цена + старая цена + скидка), `RatingStars`, `QuantityStepper`, `VariantPicker`, `FilterGroup`, `PhoneInput`, `AddressForm`, `DeliveryMethodPicker`, `PaymentMethodPicker`, `EmptyState`, `Breadcrumbs`.

Уведомления — toast (sonner): «Добавлено в корзину», «Добавлено к сравнению (2 из 4)» с действием-ссылкой.

## 14. Безопасность и персональные данные

- Соответствие Закону РБ № 99-З: явное отдельное согласие на обработку персональных данных, политика обработки ПД в открытом доступе, возможность удалить аккаунт.
- Сессия — только httpOnly, Secure, SameSite cookie; никаких токенов в localStorage.
- Валидация всех форм на клиенте и (в мок-API) на сервере одними zod-схемами; цены и суммы заказа пересчитываются на сервере, а не берутся с клиента.
- Заголовки безопасности в `next.config`: `X-Content-Type-Options`, `Referrer-Policy`, `Strict-Transport-Security`, `X-Frame-Options: SAMEORIGIN`, CSP в режиме Report-Only на старте.
